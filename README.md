# PRT Exploration

An experiment in personal rapid transit (PRT): small, light, automated vehicles
on a dedicated network with off-line stations, so every trip is nonstop and
on-demand.

Two tracks of work:

1. **Simulation** — network, vehicles, control, and demand.
2. **Engineering and design** — guideway, vehicle, switching, and stations.

See [docs/design-notes.md](docs/design-notes.md) for the starting framing:
precedents, guideway options, the hard problems, and the simulation plan.
